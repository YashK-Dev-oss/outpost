# AI Disclosure

OUTPOST was developed with assistance from generative AI tools. AI assistance was used during development, while the student team directed the project, made design decisions, integrated changes, tested the game and reviewed the final result.

## AI tools used

### ChatGPT — OpenAI
- Brainstorming and refining gameplay ideas.
- Explaining programming concepts and helping troubleshoot errors.
- Assisting with project planning, documentation and code review.

### Claude — Anthropic
- Assisting with implementation and modification of project code.
- Reviewing existing project structure and suggesting improvements.
- Helping develop gameplay features and documentation.

### GitHub Copilot — GitHub
- Providing coding suggestions and development assistance.
- Supporting code completion and troubleshooting.

## Human contribution

The student team:
- Developed the original OUTPOST concept and project direction.
- Selected and prioritised gameplay features.
- Made decisions about the game mechanics and user experience.
- Integrated and reviewed AI-assisted changes.
- Ran tests and checked the project locally.
- Prepared the project for public deployment and submission.

## Transparency

AI-generated or AI-assisted code and documentation were reviewed as part of development. The team does not claim that AI-assisted work was written entirely without AI involvement.

OUTPOST is an independent student project and is not an official NASA product or endorsed by NASA.
