# OUTPOST — Submission Checklist

NASA Space Apps Challenge 2026  
Team HORIZON

## 1. Project readiness

- [ ] Read the official challenge requirements.
- [ ] Run `npm test`.
- [ ] Run `npm run validate`.
- [ ] Run `npm run readability`.
- [ ] Run `git diff --check`.
- [ ] Complete release validation after human Codex verification.
- [ ] Test the full mission on desktop.
- [ ] Test the full mission on mobile.
- [ ] Check Training and Classroom modes.
- [ ] Check accessibility and reduced-motion support.
- [ ] Check offline loading and privacy.
- [ ] Confirm GitHub Pages loads the latest version.

## 2. NASA data and resources

- [ ] Confirm NASA DONKI is listed with its public URL.
- [ ] Confirm NASA/JPL Horizons is listed with its public URL.
- [ ] Check that all external data sources and resources are acknowledged.
- [ ] Review `docs/DATA_PROVENANCE.md`.

## 3. AI and external assistance

- [ ] Review `docs/AI_DISCLOSURE.md`.
- [ ] Disclose all AI tools used.
- [ ] Identify AI-assisted code, text, images, audio and video where applicable.
- [ ] Add visible AI-generated media watermarks where required by the challenge rules.
- [ ] Review `docs/CREDITS.md`.

## 4. NASA Space Apps submission form

- [ ] Enter the project name: OUTPOST.
- [ ] Write a 50–200 word project summary.
- [ ] Provide the public playable website URL.
- [ ] Provide a public project demo: a presentation of up to 7 slides or a video of 30 seconds or less.
- [ ] Ensure the demo is publicly accessible without a password or registration.
- [ ] Write the detailed project description, explaining what it does and how it works.
- [ ] Explain the project's benefits, intended impact, creativity and design considerations.
- [ ] List the technologies, languages, tools and resources used.
- [ ] List NASA data sources with their full public URLs.
- [ ] List all other external resources with their full public URLs.
- [ ] Complete the AI/SI disclosure questions.
- [ ] Review the final submission and accept the required terms.

## 5. Final verification

- [ ] Confirm the website works from a public browser.
- [ ] Confirm the demo link works without permissions.
- [ ] Confirm all project links are publicly accessible.
- [ ] Check spelling and accuracy across the submission.
- [ ] Submit before the official deadline.

---

**Important:** Do not mark a task complete until it has actually been checked. This checklist is for the team's internal tracking and does not replace the official NASA submission form.
