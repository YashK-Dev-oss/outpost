# Submission

## Submission checklist

- [ ] Read the official challenge page and complete the human compliance review.
- [ ] Run `npm test`, `npm run validate`, `npm run readability`, and `git diff --check`.
- [ ] Complete `npm run validate -- --release` after human Codex verification.
- [ ] Test Training, Classroom, and full missions on phone and desktop.
- [ ] Check accessibility, reduced motion, privacy, offline loading, and printing.
- [ ] Confirm the GitHub Pages build contains only relative static paths.
