# Credits

## OUTPOST

OUTPOST is a student project by Team HORIZON. It is not an official NASA
product and is not endorsed by NASA.

Space weather data comes from NASA DONKI (CCMC). Planet positions come from the
NASA/JPL Horizons System. Data files include their provenance and source notes.

The interface uses original inline SVG artwork and browser WebAudio and speech
features. No external libraries, fonts, analytics, cookies, or runtime network
requests are used. No data leaves your device.
