# OUTPOST

OUTPOST is a browser-based Mars outpost mission trainer for junior astronauts.
Phase 0 provides the static scaffold and a placeholder title screen.

## Run locally

Requires Node.js 20 or newer.

```text
npm run serve
```

Open <http://localhost:8080>.

Run tests with `npm test` and validate the data folder with `npm run validate`.

## Data sources

The planned data sources are NASA DONKI (CCMC) for space weather and NASA/JPL
Horizons System for planet positions. Real data will be added in a later phase.
